📥 결제 문자·알림 자동 입력

카드 승인 문자나 카카오페이 알림을 붙여넣으면 금액·사용처·분류를 알아서 채워요.

📱 폰에서 완전 자동으로 받는 방법

웹앱은 문자·알림을 직접 읽을 수 없어요. 대신 아래 방법으로 폰이 알림을 하루장부에 넘겨줘요.

① 공유하기 (설치된 앱, 안드로이드)
  • 문자·알림 내용을 길게 눌러 복사 → 공유 → 하루장부 선택
② 자동화 앱 (안드로이드: MacroDroid·Tasker 등)
  1. 트리거: 알림 수신 (문자 앱, 카카오페이 등) · 내용에 '승인' 또는 '결제' 포함
  2. 동작: 웹사이트(URL) 열기 → 아래 주소 뒤에 알림 내용 변수를 붙이기
③ 아이폰 단축어
  1. 단축어 앱 → 자동화 → 메시지(내용에 '승인' 포함)
  2. 동작: URL(위 주소 + 메시지 내용) → URL 열기
  3. 아이폰은 홈 화면 앱이 아닌 사파리로 열려 기록이 따로 저장돼요. Google 드라이브 동기화를 켜 두면 합쳐져요.

주소의 # 뒤 내용은 서버로 전송되지 않고 이 기기에서만 처리돼요. 취소 문자는 같은 금액의 지출을 찾아 지워 줘요.
