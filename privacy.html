하루장부 개인정보처리방침

시행일: 2026년 11월 25일

하루장부(이하 "앱")는 일정과 지출을 기록하는 개인용 웹 앱이에요. 앱은 이용자의 개인정보를 보호하는 것을 가장 중요하게 생각해요.

1. 수집하는 정보

앱은 이용자가 직접 입력한 일정, 지출 내역, 지출 탭 비밀번호(암호화되지 않은 간단한 화면 잠금용 값의 해시)를 저장해요. 앱 운영자는 이 정보를 수집하거나 볼 수 없어요. 별도의 서버가 없어요.

2. 저장 위치

  • 이용자의 기기: 모든 기록은 이용자의 브라우저(기기) 저장소에 저장돼요.
  • Google 드라이브(선택): 이용자가 "Google로 로그인"을 선택한 경우에만, 같은 기록이 이용자의 Google 드라이브 앱 전용 숨김 폴더(appDataFolder)에 파일 1개로 저장돼요. 이를 위해 drive.appdata 권한만 요청해요. 이용자의 다른 드라이브 파일은 읽거나 수정할 수 없어요.

3. 이용 목적

저장한 정보는 이용자의 여러 기기에서 같은 기록을 보여주기 위한 목적으로만 사용해요. 광고, 분석, 판매 등 다른 목적으로 사용하지 않아요.

4. 제3자 제공

앱은 이용자의 정보를 제3자에게 제공, 판매, 공유하지 않아요. 앱의 Google 사용자 데이터 이용은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따라요.

5. 보관 및 삭제

  • 기기의 기록은 앱 안에서 항목을 삭제하거나 브라우저 사이트 데이터를 지우면 삭제돼요.
  • Google 드라이브의 기록은 앱 설정의 "로그아웃" 후, Google 계정의 앱 연결 관리에서 하루장부 접근을 해제하고 저장된 앱 데이터를 삭제하면 지울 수 있어요.

6. 쿠키 및 추적

앱은 광고용 쿠키나 추적 도구를 사용하지 않아요. 앱 작동을 위해 브라우저 저장소(localStorage)와 오프라인 사용을 위한 캐시만 사용해요.
