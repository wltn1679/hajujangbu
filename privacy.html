하루장부 개인정보처리방침

시행일: 2026년 11월 25일

하루장부(이하 "앱")는 일정과 지출을 기록하는 개인용 웹 앱이에요. 앱은 이용자의 개인정보를 보호하는 것을 가장 중요하게 생각해요.

1. 수집하는 정보

앱은 이용자가 직접 입력한 일정, 지출 내역, 다이어리 글, 첨부한 사진(압축본), 잠금 비밀번호(화면 잠금용 값의 해시)를 저장해요. 앱 운영자는 이 정보를 수집하거나 볼 수 없어요. 별도의 서버가 없어요.

결제 문자·알림 자동 입력: 이용자가 붙여넣거나 공유하기·자동화 앱으로 넘긴 결제 문자 내용은 이 기기 안에서만 분석해 금액·사용처·날짜만 지출 기록으로 저장하고, 문자 원문은 저장하지 않아요(중복 방지용 해시값만 보관). 앱은 문자나 알림을 직접 읽지 않으며, 이용자가 설정한 경우에만 내용이 넘어와요. 주소의 # 뒤에 담긴 내용은 서버로 전송되지 않아요.

2. 저장 위치

  • 이용자의 기기: 모든 기록은 이용자의 브라우저(기기) 저장소에 저장돼요.
  • Google 드라이브(선택): 이용자가 "Google로 로그인"을 선택한 경우에만, 같은 기록이 이용자의 Google 드라이브 앱 전용 숨김 폴더(appDataFolder)에 기록 파일 1개와 첨부 사진 파일들로 저장돼요. 이를 위해 drive.appdata 권한만 요청해요. 이용자의 다른 드라이브 파일은 읽거나 수정할 수 없어요.

2-1. 안드로이드 앱의 알림 접근

안드로이드 앱은 이용자가 직접 허용한 경우에만 '알림 접근' 권한으로 카드 승인·입금 알림을 읽어 장부에 기록해요. 금액과 결제·입금 관련 단어가 들어 있는 알림만 이 기기 안에 임시로 보관하고, 장부에 기록한 뒤 지워요. 그 밖의 알림(대화, 인증번호 등)은 저장하지 않아요. 이 내용은 기기 밖으로 전송되지 않으며, 앱은 인터넷에서 하루장부 화면을 불러오는 것 외에는 어디에도 연결하지 않아요. 권한은 기기 설정에서 언제든 끌 수 있어요.

3. 이용 목적

저장한 정보는 이용자의 여러 기기에서 같은 기록을 보여주기 위한 목적으로만 사용해요. 광고, 분석, 판매 등 다른 목적으로 사용하지 않아요.

4. 제3자 제공

앱은 이용자의 정보를 제3자에게 제공, 판매, 공유하지 않아요. 앱의 Google 사용자 데이터 이용은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따라요.

5. 보관 및 삭제

  • 기기의 기록은 앱 안에서 항목을 삭제하거나 브라우저 사이트 데이터를 지우면 삭제돼요.
  • Google 드라이브의 기록은 앱 설정의 "로그아웃" 후, Google 계정의 앱 연결 관리에서 하루장부 접근을 해제하고 저장된 앱 데이터를 삭제하면 지울 수 있어요.

6. 쿠키 및 추적

앱은 광고용 쿠키나 추적 도구를 사용하지 않아요. 앱 작동을 위해 브라우저 저장소(localStorage)와 오프라인 사용을 위한 캐시만 사용해요.
